# Activity Codes

ATOC activity codes matched to GTFS pickup_type and drop_off_type
values.

## Usage

``` r
activity_codes
```

## Format

A data frame code 3 columns

## Details

Within the CIF files an Activity code identifies what happens at each
location. A full set of activity codes is listed at
https://wiki.openraildata.com/index.php?title=Activity_codes. It is
possible to have multiple activities happening at the same location.
This file contains a look up table to match groups of activity code with
their corresponding form in the GTFS file.
